# 混合楼距与突发路障（2026-10-04）

用户反馈所有楼距都要二段跳过于单一，明确要求近远交替并增加突然出现的障碍。本次保留二段跳操作，修改生成节奏和部分路障的出现时机。

## 楼距

起始间隙为近距离，随后以种子打乱每组三种楼距的顺序；每组各一个近、中、远，最多相邻两次同类，不会长时间只生成远距。

| 基础进度 | 近距（px） | 中距（px） | 远距（px） |
| --- | --- | --- | --- |
| 0–150 | 64–80 | 86–98 | 142–170 |
| 150–500 | 75–94 | 101–115 | 174–198 |
| 500+ | 86–108 | 116–132 | 206–230 |

近、中距离必须通过单跳可达性检查，远距离采用二段跳轨迹检查，均保留 14px 余量并排除不跳就能跨越的组合。近、中鱼干回到屋顶上方 54px，远距为 112px。中距离需要更准确的起跳时机；不会为了使用二段跳把所有楼都拉远。

## 突发路障

- 第一处路障（平台 ID 3）采用突发形式；之后每个障碍屋顶按种子以 55% 概率选择突发，其余保持固定路障。
- 尚未接近时隐藏；小猫前缘进入 243px 距离时，显示空心轮廓、像素感叹号和 DOM 文字「前方路障即将升起！」。350ms 后切换为实体挡板并启用碰撞。
- 按最快 270px/s 计算，从预警到到达路障约 900ms，实体升起后仍约有 550ms。离散步长可能带来一个模拟步的偏差。按最大速度预留距离，阶段切换也不会压缩成即时伤害。
- 预警只用模拟时间，不用计时器、系统时间或视口边界；暂停冻结计时，恢复接着走，重开恢复隐藏状态。同种子同输入可复现。
- 路障仍位于 340px 长平台，尺寸 24×20px，左侧至少 120px、右侧至少 172px；预警期间不伤害，升起后保留扫掠碰撞。隐藏时也隐藏其上方奖励弧线。
- 静音时仍有完整视觉预警；静态轮廓与感叹号无需闪烁，减少动态设置不改变规则。

## 验证

- 新增预警距离/完整时长、隐藏和预警不伤害、激活碰撞、无模拟推进时冻结、重开复位及实际避障路径测试。
