# 手感与挑战调整（2026-10-03）

> 本文记录上一版参数；2026-10-04 起跳跃次数、楼距与间隙鱼干高度以 [二段跳说明](DOUBLE_JUMP.md) 为准。

## 问题与目标

用户反馈挑战不足、操作手感差。原跑速仅 150/162/175 逻辑 px/s，屋顶较长，阶段差异偏弱；输入只有按下瞬间落地才生效。此次保持单次跳跃、办公外观、默认静音和显式继续。

## 参数

| 参数 | 旧值 | 新值 | 理由 |
| --- | --- | --- | --- |
| 跑速（逻辑 px/s），0–150 / 150–500 / 500+ 分 | 150 / 162 / 175 | 200 / 235 / 270 | 提升节奏与阶段差异 |
| 跳跃速度（逻辑 px/s） | -370 | -420 | 配合重力保留清楚弧线 |
| 重力（逻辑 px/s²） | 1050 | 1500 | 同高度腾空约 0.705s 降至 0.56s，减少漂浮感 |
| 屋顶宽度（逻辑 px） | 170–230 / 130–190 / 105–160 | 125–180 / 100–150 / 80–125 | 高分段需更频繁判断起跳 |
| 间隙采样范围（逻辑 px） | 54–68 / 62–80 / 68–90 | 62–78 / 74–96 / 84–110 | 扩大间距变化，仍经过可达性筛选 |
| 相机最大追踪速度（逻辑 px/s） | 14 / 18 / 23 | 80 / 110 / 140 | 跟上更快的短平台连续跳跃 |

输入缓冲为下落时 100ms，离边容错为 60ms，均按模拟时间消耗；起跳消耗一次机会，空中不能二段跳。暂停清除缓冲，重开清除所有容错计时和跳跃计数。缓冲落地后的起跳仍有声音反馈。

初级同高度的中心化计算起跳窗口约 170ms（不含角色宽度与离边容错）；后期最长平台完整横穿时间小于 0.47s。生成器还以最低跑速校验前方平台，防止预生成跨难度边界出现过远落点；起始高度范围下界为世界 y=420，避免初段向上随机漂移挤入 HUD。

## 修复和开销

- 修复走出边缘后在同一帧以零穿越时间重新吸附回旧平台的问题。
- 相机保存最后安全落地目标，在下一跳途中继续平滑追踪该目标；不追逐下落中的小猫。加速测试曾复现 seed=1、约 50 秒时相机落后导致错误失败，现保留长局回归覆盖。
- 视口宽度不变时不重复补平台；平台只在需要移除时原地裁剪；分数改变才更新 DOM；跳跃不重复重建 HUD 图标。
- 未添加依赖或调试开关，不宣称未经性能采样的 FPS 提升。

## 验证

47 项单测通过，包含 24,000 次生成可达性验证、300 个种子的 60 秒理想输入、三次 180 秒连续长局、跨视口同输入确定性、100 个种子盲目每 100ms 连点在 30 秒内至少 90 局失败，以及输入缓冲/过期/暂停清理/重开和离边后不允许二段跳。

生产构建本地浏览器操作验证键盘与指针跳跃、开始、暂停、显式继续、失败与重开；检查 360×640、390×844、430×932、1366×900 视口，控制台未见错误。类型检查与生产构建通过。

尚未复验 iPhone Safari、Android Chrome 实机与低端设备帧时间；主观难度仍需用户试玩反馈。本地最高分继续保留，不与旧版成绩强制比较。
