# 二段跳与远楼距（2026-10-04）

用户明确要求增加二段跳、拉远楼距来提高操作难度。这一决策替代早期 MVP 的单次跳跃限制，继续使用同一个跳跃按键/轻触动作。

## 操作与数值

- 落地恢复 2 次跳跃。第一次起跳后，空中再按一次可重新起跳；第三次不再提升。两次均将垂直速度设为 -420px/s，重力仍为 1500px/s²，不叠加速度。
- 按住键不重复触发。走出楼沿后 60ms 内仍有地面跳跃机会；超过后只保留 1 次空中补跳。两次耗尽后，下落末尾可缓存 100ms 的落地起跳输入。
- 暂停清除缓存但不补充次数；真实落地与重开才恢复次数。HUD 显示「可跳 2/2、1/2、0/2」。
- 三阶段楼距由原先 62–78 / 74–96 / 84–110px，调整为 142–170 / 174–198 / 206–230px；跑速仍为 200 / 235 / 270px/s。阶段仍按不含鱼干的基础进度分计算。
- 第一段跳跃顶点约在 280ms；在顶点附近使用第二次跳跃可延长同高度飞行至约 956ms。连续快速连按会提前耗尽机会，不能代替判断楼沿和落点。
- 平台生成以二段跳轨迹计算可达范围，保留 14px 余量。生成难度使用出发楼顶的基础进度估计，与视口宽度无关；批量模拟覆盖跨阶段速度变化。
- 间隙鱼干高度从较高屋顶上方 54px 改为 112px，贴合二段跳路线。路障尺寸和长平台安全空间不变，落地后可继续越障。

## 验证

- 55 项测试全部通过，包含 24,000 次平台生成、300 种种子各 60 秒长局、连续三次 180 秒长局与跨视口一致性。
- 新增远间隙单跳失败/二段跳成功对照、二段跳速度重置、第三次无效、离边补跳、落地恢复及重开复位测试；保留输入去重、暂停清理和盲目连点失败检查。
- TypeScript 与生产构建通过，无新增依赖。
- 本地生产预览实际使用键盘第一跳、画布指针第二跳，跨过第一处远间隙并收集鱼干；落地恢复至 2/2。另验证三次连续输入限制、暂停/继续、失败与重开。
- 360×640、390×844、430×932、1366×900 布局检查通过，控制台无错误。
- iPhone Safari、Android 真机和低端设备性能尚未复验；旧版实机验收不能视作本版验收。
