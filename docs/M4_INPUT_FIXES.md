# M4 输入与跨视口一致性修复

日期：2026-10-02。

## 决策与变更

- 平台生成难度改为按前一平台的世界位置及平台序号估算进度：`floor(max(0, x - 70) / 15) + id * 8`。原先使用生成时的本局分数，宽屏预生成会导致同种子的平台在难度边界分叉。新规则只依赖已生成地形；实际计分、跑速和三个阶段阈值保持原配置。该调整会改变旧版本种子的地形序列，复现时需同时记录代码版本。
- 键盘游戏操作只接受游戏容器或画布自身的事件，保留按钮等子元素的原生键盘行为；指针只接受主指针左键，捕获丢失后释放输入锁。
- 游戏区域焦点移到外部或丢失时发出独立中断动作，仅暂停，不会切换成继续。区域内部按钮间移动不暂停；重新获得焦点仍需显式继续。

## 验证

- `npm test`：11 个文件、41 项测试通过。
- `npm run build`：类型检查及生产构建通过。
- 新增三个种子各 90 秒的相同输入模拟，覆盖手机、桌面和反复缩放；平台、角色、分数一致，并经过 150/500 分阶段。
- 新增按钮键盘、按键重复、右键/中键、非主指针、指针取消/捕获丢失、焦点进出及监听器移除测试。
- 本地生产预览浏览器：静音按钮空格不启动游戏；空格开始、暂停、继续；Tab 离开自动暂停、返回不自动恢复；鼠标继续、右键及 P 暂停路径通过，检查时无控制台警告或错误。
- 本地浏览器不操作正常失败，鼠标重开后分数重置，画布左键跳跃及按钮暂停通过。
